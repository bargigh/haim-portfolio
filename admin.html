Gallery Manager (ניהול גלריה)

How this works, Haim:
1. Change any photo's category with its dropdown, or tap ⟳ to rotate it.
2. Changed photos get a yellow border.
3. When you're done, press the green "Export changes" button — it downloads a small file.
4. Send that file to gail (WhatsApp/Telegram/email) — gail applies it to the live site.
Changes here are NOT live until gail commits them — this page only prepares the change file.
Categories — rename by editing a name, ✕ deletes (its photos move to Portraits), or add a new one below.
